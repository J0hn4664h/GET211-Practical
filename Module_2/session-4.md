## Practical session 4

1. Flowchart: CGPA Calculation
Plain text
(Oval) START
(Parallelogram) INPUT course grades and credit units
(Rectangle) Multiply each grade by its credit unit
(Rectangle) Sum all grade points
(Rectangle) Sum all credit units
(Rectangle) CGPA = total grade points / total credit units
(Parallelogram) OUTPUT CGPA
(Oval) END

2. Flowchart: Water Tank Level Control
Plain text
(Oval) START
(Parallelogram) INPUT water level sensor reading
(Diamond) Is water level LOW?
(Rectangle) YES → Turn ON pump
(Rectangle) NO → Turn OFF pump
(Parallelogram) OUTPUT pump status
(Oval) END
