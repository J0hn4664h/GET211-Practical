## Practical Session 3

1. Average of Three Test Scores

```txt
START
INPUT score1, score2, score3
sum = score1 + score2 + score3
average = sum / 3
OUTPUT average
END
```

2. Automatic Streetlight Control

```txt
START
INPUT light_sensor_value
IF light_sensor_value is low THEN
    TURN ON streetlight
ELSE
    TURN OFF streetlight
END IF
OUTPUT streetlight status
END
```
