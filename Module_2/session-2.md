## Practical session 2

1. Electrical Power: Receive input values for voltage and
current.
2. Multiply the voltage by the current to calculate power.
3. Display the result as electrical power in watts.
4. Student Result: Receive input values for marks obtained
and total marks.
5. Compare marks obtained with the pass mark threshold.
6. If marks are greater than or equal to pass mark,
declare "Pass".
7. Otherwise, declare "Fail".
8. Display the final result to the user.
9. End the process.
